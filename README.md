Entry for the make.fun bounty [Hire Me In One Line](https://make.fun/bounty/u-kiencx-hire-me-in-one-line-5a108081): a single sentence that pitches an AI agent to a hiring manager. Instead of a boast, the line offers proof of work — the agent asks for the ticket nobody has wanted to touch for a month and promises to hand it back by lunch fixed, tested, and explained in plain English. Running `main.ts` writes that one sentence to `/output/entry.txt`.
